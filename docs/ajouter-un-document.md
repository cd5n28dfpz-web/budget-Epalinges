# Ajouter un document (nouveau budget ou nouveaux comptes)

1. Télécharger le PDF depuis le site de la commune ([epalinges.ch](https://www.epalinges.ch)) et le placer dans `sources/pdf/`, sous le nom `budget-2027.pdf` ou `comptes-2026.pdf`. Prendre le fichier original (Enregistrer sous).
2. Ajouter une entrée dans `sources/documents.json` : `id`, `fichier`, `type` (`budget` ou `comptes`), `annee`, `titre`, `url`, et les colonnes du tableau « détail par service » dans l'ordre (`projet:2027`, `budget:2026`, `comptes:2025`… ; 3 ou 6 colonnes selon le document). Pour un document dont les pages de détail sont des images : `"pages_ocr": [début, fin]` et `"pages_detail": [début, fin]` (numéros de pages du PDF).
3. Lancer `make all`. L'extraction vérifie que chaque montant tombe dans une colonne ; la fusion contrôle les totaux de chaque service, groupe, fonction et dicastère, et le total général contre le tableau « TOTAUX » du document.
4. Lire le résumé affiché : aucun contrôle bloquant ne doit être en échec. Les écarts sont listés dans `data/controles.csv`.
5. Pour les pages lues par OCR (`tesseract` et `opencv-python-headless` requis), comparer avec l'image du PDF chaque ligne signalée par un contrôle. Les corrections vérifiées vont dans `sources/corrections.csv` (document, type, service, compte, colonne, valeur, raison).
6. Mettre à jour `OFFICIELS` dans `tests/test_donnees.py` avec les totaux relevés dans le document, puis committer `sources/documents.json`, `sources/corrections.csv`, `sources/extraits/`, `sources/ocr/`, `data/` et `site/` (le PDF lui-même n'est pas versionné).
